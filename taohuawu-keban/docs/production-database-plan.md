# 本应用生产数据库实施边界

用户已于2026-11-11对上一条明确的“本应用生产数据库开通及迁移”请求回复“授权”。Gate A和冻结身份已核对；SaaS26只读审查确认没有现成PostgreSQL进程/客户端或Docker，不把MySQL冒充目标复杂存储。

采用本应用专属目录 `/www/server/thwkb.zh.huawei`，不在网站静态根目录保存凭据，不安装/升级系统包或共享数据库。PostgreSQL17.11从官方HTTPS源下载并核对官方SHA256，单任务低优先级构建；不改其他应用依赖。实例仅监听127.0.0.1:55426，使用本应用无登录系统账号、独立数据目录、SCRAM密码和非超级用户业务角色。受保护凭据仅保存在远端root专属目录，不能打印、写入命令参数、客户端或提交。

数据库与表仅本应用：`thwkb_zh_huawei`、冻结的16个thwkb实体及迁移登记。两份既有迁移按顺序执行，不修改001历史内容；执行前备份本应用数据库，执行后核对版本、表与约束。公开种子发布审批仍false，不导入待核验素材，不将数据库授权当成版权批准。

新增实例或数据目录如已存在且无本应用所有权标识即停止。启动配置/备份/运行日志均放在本应用目录；进程管理只增加本应用进程，不重启或覆盖其他租户。应用API部署前须另核对远端精确增量，不能上传整个本机dirty平台dist。

回退保持数据可恢复：停止新建的本应用数据库进程、保留数据/备份/凭据并移除新增应用入口；不自动drop生产数据库、角色或删除系统账号，不恢复整套共享站点。若数据库已有用户写入，先核对备份与迁移影响，不用旧文件覆盖新记录。

实际结果以docs/validation/deploy下运行记录为准。此方案和授权文件不是迁移成功或Gate B通过证明。
