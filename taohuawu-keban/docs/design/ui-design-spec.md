# 桃花坞刻版 UI 设计规范

设计基于用户指定的萌系国潮、原创角色、轻木刻质感，主任务为从图鉴进入组合创作、保存并恢复作品。

## 统一设计语言

桃花粉 #F2A6B8 用于选中和柔和色面，朱砂红 #D95C52 用于主要操作，杏花黄 #F5D58A 用于专题强调，奶油白 #FFF8F0 为页面底色，豆青绿 #A8C9AE 为文化/素材辅助色，墨棕 #493B3A 为正文。深色按钮底色采用 #A93635，使浅色文字具有足够对比；浅桃色只用于深色文字背景。

字体采用系统 HarmonyOS Sans，确保中文覆盖与平台缩放；不打包来源不明字体。标题 24/20，正文 16，辅助信息 14，版权与来源说明 12；正文行高约 1.5，长文左对齐。避免把说明压到 10 以下。

页面水平留白 20vp，区块间隔 28vp，卡片内边距 16vp，元素间距 8/12vp。Banner 圆角 24、作品卡 18、标签 10、按钮 14；不把所有容器做成同一种卡片。图鉴封面 4:3，作品画布 4:5，角色立绘 contain，场景 cover。所有可点击入口至少 44vp。

## 页面构图

首页用品牌标题、搜索和单张大幅主题 Banner 建立首屏；专题以双列图鉴入口组织，精选角色横向陈列，作品采用双列封面，知识用图文横排。模块顺序由首页 API 的编排提供，滚动到底加载作品，下拉重新读取；内容为空时隐藏空模块并给出可操作入口。

图鉴采用左对齐标题、可滚动分类标签与双列角色卡；角色详情以透明全身立绘和单一底色舞台开场，原创故事、文化灵感、造型配色分别标注，来源可展开。详情底部收藏和进入工坊为固定操作。

工坊首页突出模板预览和继续草稿。编辑器以 4:5 画布为中心，上方返回/撤销/保存，下方工具栏切换角色、背景、贴纸、文字、印章；选中图层显示边框，拖动改变位置，滑杆改变大小，颜色选项和输入框实时反映到画布。保存中禁止重复提交，离开有未保存修改时确认。

广场用官方/用户来源标签和审核通过状态控制展示；作品详情强调作品本身，作者、素材版权和互动置于下方。我的使用个人摘要、作品/草稿/收藏三个视觉入口与设置列表，不采用首页式长 Banner。

## 交互与状态

加载显示进度或骨架；失败给出具体原因及重试；无搜索结果提示修改关键词；草稿为空引导选择模板；收藏为空引导浏览图鉴。网络异常不把本地草稿标为云端保存成功。

动效仅用于用户触发的选中、工具切换、图层移动和保存反馈，持续 150–240ms；不自动漂浮所有角色。用户缩放字体后保持按钮可达，正文不截断，长标题至多两行。宽屏采用内容最大宽度和双栏编辑布局。

## 设计复核

已将“所有模块共用圆角卡片”的初稿方向调整为 Banner、立绘舞台、双列封面、图文阅读与画布工具五类层次。奶油底和桃粉来自用户明确品牌要求；视觉重心放在原创角色和套色创作，装饰限制在边缘。最终体验仍须通过真机/模拟器截图及 Gate C，本文不构成验收通过。
