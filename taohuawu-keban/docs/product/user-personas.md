# 用户角色与场景

## 国潮插画与动漫爱好者

在通勤或休息时浏览统一画风的角色与作品，希望快速进入模板，在手机上完成有明显个人差异的组合创作，并能下次继续编辑。

## 传统文化兴趣用户

从生肖、瑞兽、节气或工艺专题进入内容，希望看到适合移动阅读的图文排版、可复核来源，并明确知道哪些是历史资料、哪些是现代原创表达。

## 原创内容创作者

管理草稿和作品版本，提交公开展示，关注审核结果与互动；需要版权来源记录、可解释的状态流转和账号间严格隔离。

## 内容运营与审核人员

在管理端维护公共分类、角色、知识文章、授权素材、模板和首页编排；对用户发布、举报和下架进行审核。此角色不通过 C 端获得越权能力。
