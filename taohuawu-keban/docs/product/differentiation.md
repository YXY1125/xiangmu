# 差异化说明

对照 `lqzks.tdx.huawei`、`txmop.zy.huawei`、`qiaosi-sheji` 与 `ptxj.wb.huawei`，本应用至少有以下可核对差异：

1. 核心创作对象是桃花坞年画语义下的角色、背景、贴纸、印章和祝福文字图层，不是竹刻扇面纹样、提线木偶关节、古今设计案例或照片拼贴。
2. 主导航固定为首页、图鉴、工坊、广场、我的；非遗课堂作为内容详情体系，不复制其他应用的艺术馆、技艺课堂、灵感图鉴或照片时间线。
3. 角色详情强制分离历史来源与现代原创设定，保存文化寓意、设计灵感、色彩造型和相关作品；不是普通 `title + summary + cover` 内容卡。
4. 工坊画布保存完整图层矩阵、颜色、文字、层序和修订号，并要求服务端恢复；不是本地一次性预览或点击替换文案。
5. 广场区分官方与用户原创，用户发布经过 `submitted/approved/rejected/offline` 状态机并关联版权声明、举报和通知；其他参考应用没有同一公开治理闭环。
6. 首页采用萌系国潮编辑式 Hero、非对称角色/生肖叙事和进入工坊的唯一主动作，不使用三 KPI、通用快捷宫格、AI 横幅或戏台/扇面构图。
7. 品牌锚点为“桃”字、桃花花瓣与木版刻刀负形，色彩为桃花粉、朱砂红、杏花黄、奶油白、豆青绿和墨棕；不复用参考应用 Logo、图片或视觉母题。
8. 内容事实核验是数据模型一部分：知识文章保存来源记录和 `factCheckStatus`，原创角色保存独立 `originalStory`；不会把虚构设定混入历史正文。
9. 首期明确关闭生成式 AI，创作依赖授权本地素材和原生图形能力，不复用任何 AI 对话、问卷或生成接口。
10. 新用户私人数据为空；公共文化内容与个人记录分源加载，首页的“最近浏览”和“最新创作”按登录身份单独请求，不用平台种子冒充个人行为。
