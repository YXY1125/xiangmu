# 页面架构

## 主导航

`首页 → 图鉴 → 工坊 → 广场 → 我的`

工坊是居中的主任务入口，但不扩大点击热区或破坏无障碍标签。首页搜索覆盖角色、知识与公开作品，结果按内容类型分组。

## 页面层级

- 首页：主题 Banner、精选角色、生肖、瑞兽、图鉴、作品、排行、知识、最近浏览。
- 图鉴：分类筛选 → 角色/作品列表 → 角色详情 → 相关作品或进入工坊。
- 工坊：模板选择 → 素材选择 → 编辑器 → 草稿/正式作品 → 导出/发布。
- 广场：精选/最新/热门/分类 → 作品详情 → 作者主页、点赞收藏分享举报。
- 我的：个人资料、作品、草稿、互动记录、历史、消息 → 设置与隐私 → 协议、退出、注销。

## 管理端范围

App 注册用户、公共分类、角色、知识文章、专题、素材与授权、创作模板、首页编排、用户作品审核、举报处理、通知、租户配置和统计。管理端与 C 端使用同一 saas26 租户数据源；未实现和未部署前不得宣称后台已可用。
