日期：2026-11-11。来源：本项目用户在当前会话中的明确指令。

用户原文：“所有素材都是你生成的呀，你保存到哪里了，就从哪里上传”。此前用户已授权生产 API 集成、设备测试和 Gate B/C 验收。

本记录是用户对本项目生成素材上线使用的授权记录，不是外部法律审查、著作权登记证书或独占权利证明；不宣称已取得此类证明。生成来源及现代原创与历史资料的边界继续保留。后续用户投稿仍须独立提交权利声明并经管理员审核，不能由本记录自动批准。

机器核验记录由 `tools/approve_content_release.mjs` 生成，逐个比对原始 PNG 与 WebP 的实际哈希。只批准匹配台账的既有素材，不批准未来新增、替换或来源不明的文件。知识文章继续要求来源记录和事实核验。

本次只授权素材与已规划的官方公共内容导入；不代表 Gate B、Gate C、发布签名或应用商店审核通过。
