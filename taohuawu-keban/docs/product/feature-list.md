# 功能清单与验收边界

## 五个主 Tab

1. 首页：桃花秘境，含真实数据驱动的主题、精选、角色、生肖、瑞兽、图鉴、作品、排行、知识和最近浏览。
2. 图鉴：角色与年画题材分类、搜索、筛选、详情、收藏、点赞和相似推荐。
3. 工坊：模板、角色、背景、贴纸、色彩、文字、印章、图层操作、实时预览、草稿/作品保存恢复、导出分享。
4. 广场：官方作品、审核通过的用户作品、搜索分类、详情、作者、互动、分享、举报。
5. 我的：个人资料、作品、草稿、收藏、点赞、历史、通知、反馈、设置和账号注销。

## 非 Tab 页面

知识专题与文章详情、角色详情、作品详情、作者主页、创作编辑器、作品发布、审核记录、消息通知、登录注册、设置与隐私、协议全文。

## 真实能力判定

- 首页公共栏目由 saas26 当前租户公开内容接口返回；网络失败显示错误/重试，不回填本地假列表。
- 游客可浏览已发布公共内容；所有写操作先通过认证门禁。
- 编辑器图层状态包含素材引用、矩阵位置、缩放、旋转、颜色、文字、层序和画布版本；保存后由服务端返回修订号，恢复时完整重建。
- 分享和导出使用系统能力；没有真实字节与成功回调时不显示为成功。
- 收藏、点赞和浏览关系具有唯一约束，重复动作幂等。
- 新账号的草稿、作品、收藏、点赞、历史和通知为空。
