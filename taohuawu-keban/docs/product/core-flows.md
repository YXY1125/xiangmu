# 业务闭环

## 创作保存与恢复

选择模板 → 加入授权素材 → 修改位置/大小/层序/颜色/文字 → 实时预览 → 登录门禁 → 保存草稿 → 服务端返回 `id + revision` → 我的草稿查看 → 再次打开按 `canvasState` 恢复 → 继续编辑或生成正式作品。

保存失败时保留当前画布，显示明确错误和重试；不得提前显示成功。并发更新按修订号检测冲突，旧响应不得覆盖新画布。

## 发布审核

本人正式作品 → 填写说明与版权声明 → 提交 → `submitted` → 审核 `approved/rejected` → 只有 `approved` 进入广场；举报后进入复核，可下架为 `offline`，状态变化生成当前用户通知。

## 内容学习

分类或搜索 → 角色/文章详情 → 查看文化资料、来源与原创说明 → 收藏或记录浏览 → 查看相关作品 → 使用相关授权素材进入工坊。

## 账号隔离

账号 A 注册并保存草稿、收藏与历史 → 退出清理 token、AppStorage、Preferences 中会话及私有页面缓存 → 账号 B 登录后私有列表为空且无法通过 ID 访问 A 数据 → 账号 A 重新登录后从服务端恢复自己的记录。
