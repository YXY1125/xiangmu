# 桃花坞刻版视觉方向与验收入口

权威声明来自 AppSpec v1.3：stylePack=cute-guochao-editorial，productVisualType=content-commerce。沿用已建立的萌系国潮角色、轻木刻质感和套色创作方向，不在联调阶段另建风格体系。

色彩、系统字体、间距、图像比例和页面布局以 docs/design/ui-design-spec.md 为准：桃花粉 #F2A6B8、朱砂红 #D95C52、杏花黄 #F5D58A、奶油白 #FFF8F0、豆青绿 #A8C9AE、墨棕 #493B3A。主要深底按钮使用 #A93635；对比度及深色模式仍须逐屏实测，不以色值声明代替验收。

首页重心为真实主题插画、角色和作品，知识图文横排；图鉴使用立绘与双列卡，编辑器使用4:5画布，个人中心围绕用户作品和草稿。文字按系统HarmonyOS Sans与既有层级处理，避免以装饰压缩文化来源和原创设定说明。

影像文件与用途索引见 visual-assets.md；完整逐图来源、尺寸和哈希见 docs/ImageManifest.md；WebP派生映射及质量记录见 docs/validation/engineering-images.json。传统文化事实与现代角色故事必须分标，不复制传统原作作为品牌视觉。

首页效果图状态：缺失，docs/product/mockups/ 当前没有已确认首页效果图。现有原始Banner不是完整页面效果图，黑屏系统诊断也不是效果图。待独占设备正常运行后对照真实首页形成可审核版本，再由实际验收结论更新；本索引不代表该项完成。

frontend-design复核原则：保持用户明确的奶油底与桃粉，不改成无关模板；将差异放在原创角色与套色画布，保留详情阅读、图鉴和工坊不同层次。最终以 Gate C 的实机效果、适配、可读性和图标一致性检查为准。
