# 原创 IP 角色设定

所有角色均为现代原创设定，不是桃花坞木版年画历史人物，不应写入“真实历史”栏目。文化灵感只描述通用吉祥意象，正式文化解读仍需引用可靠来源。

## 桃夭｜桃花小使者

- 定位：平台主引导角色与工坊向导。
- 外观：花瓣形双环发髻、短款交领上衣、层叠裙和刻刀吊饰。
- 配色：桃花粉、奶油白、豆青绿、少量朱砂。
- 性格：好奇、爽朗、愿意把复杂工艺讲清楚。
- 文化灵感：桃花与套色印刷的色版层次。
- 原创说明：以现代动漫服饰和印刷调色盘重新组织，不复刻传统人物造型。

## 团团｜十二生肖萌团代表

- 定位：生肖分类引导与任务伙伴；首期代表为兔。
- 外观：长耳、桃形额记、十二色圆盘挎包和短款节庆外套。
- 配色：奶油白、豆青、杏黄与桃粉。
- 性格：机灵、行动快、喜欢收集不同生肖的颜色。
- 文化灵感：生肖兔的敏捷与团圆寓意。
- 原创说明：动物潮玩比例与现代挎包系统，不对应任何传统年画原作。

## 霁麟｜祥瑞小灵兽

- 定位：瑞兽图鉴守护者。
- 外观：小型四足麒麟体态、珊瑚鬃、金色幼角、豆青鳞片与桃花铃。
- 配色：奶油白、珊瑚红、豆青、杏黄。
- 性格：温和、谨慎、遇到不可靠史料会停下来核对。
- 文化灵感：麒麟的祥瑞意象与云纹。
- 原创说明：弱化威猛龙兽元素，建立独立的幼兽轮廓和花铃配饰。

## 阿福｜吉祥娃娃

- 定位：节庆主题与互动节奏角色。
- 外观：短发、现代交领街头服、宽裤、桃结运动鞋和双面节奏鼓。
- 配色：朱砂、杏黄、奶油白与豆青。
- 性格：热情、可靠、幽默，负责提醒发布与审核规则。
- 文化灵感：节庆鼓乐与吉祥结。
- 原创说明：不使用“福神”等真实神祇身份，不在服装上直接写传统吉祥字样。

## 绯鲤｜好运锦鲤

- 定位：好运主题、点赞与收藏反馈角色。
- 外观：圆润锦鲤体态、桃瓣长鳍、豆青波纹绶带与方形花印。
- 配色：朱砂珊瑚、桃粉、奶油白、豆青。
- 性格：乐观、慷慨、情绪夸张但不制造“转发必好运”等误导承诺。
- 文化灵感：鱼的丰足与吉庆意象。
- 原创说明：不复刻传统锦鲤画构图，采用透明长鳍与现代配饰。

## 蕊灵｜花间精灵

- 定位：花鸟、节气和色彩主题引导角色。
- 外观：莲与牡丹组合花冠、叶脉翼、花瓣披风和莲蓬印章。
- 配色：桃粉、奶油白、豆青与杏黄。
- 性格：安静、细致、擅长色彩与构图实验。
- 文化灵感：四季花卉与生长意象。
- 原创说明：不是花仙历史传说复述，角色故事属于应用原创世界观。
