# 桃花坞刻版 Logo 规范

## 设计理念

品牌锚点为“桃”。五瓣桃花表达名称与萌系国潮气质，中央木版刻刀负形表达“刻版”和数字创作工坊。图形只使用两个语义元素，避免把传统年画人物直接缩成图标。

## 色彩规范

- 图标背景：深朱砂 `#7B2F39`
- 图标前景：奶油白 `#FFF8F0`
- UI 主色：桃花粉 `#F2A6B8`
- UI 辅色：朱砂红 `#D95C52`

## 尺寸规范

- `icon_single.png`：1024×1024 PNG，直角、不透明、四周安全区不少于 25%。
- `icon_foreground.png` / `icon_background.png`：1024×1024 分层资源。
- 最小显示：24px；此尺寸保留五瓣轮廓和中央刻痕。

## 使用规范

- AppGallery 单层图：`store/logo/preview-1024.png`
- 横版：`store/logo/logo-horizontal.svg`
- 不得添加投影、渐变、发光、圆角蒙版或改变花瓣比例。
- 与正文插画分工：Logo 不作为角色或内容图使用。
