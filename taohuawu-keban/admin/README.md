# 桃花坞刻版管理入口

复用 platform/admin 单一平台站点，不独立部署App后台。新增菜单为作品审印台、版权与内容复核、创作者来信、图鉴与素材状态；注册用户与活跃仍使用平台现有页面。

管理员通过平台真实登录并选择 thwkb.zh.huawei 活动租户。tenant_operator只读，tenant_admin/platform_super可按服务端允许的状态流转处理。页面不预填口令、不内置Token、不提供本地认证旁路。

所有操作调用冻结契约中的 /biz/thwkb.zh.huawei/admin/*，与App读取同一业务服务和PostgreSQL仓库。作品审核预览使用该作品不可变画布快照和本App工程WebP；缺少快照不得批准。审批版权复选框默认不勾选，拒绝/下架必须填写原因，写入需确认；失败保留队列并可刷新。

当前只实现既有内容的状态管理，不宣称已有公共内容新增/正文编辑、运营统计或配置接口。行业包的泛化任务/成就不属于本应用需求，不添加虚假模块。数据创建仍是受版权审核约束的种子导入，生产批准未完成。

本地SFC构建与接口用例不等于生产管理闭环。生产数据库、API、公共内容与91张WebP已上线；管理员真实账号、管理端隔离部署和审核后App刷新联调仍未完成。隔离组件构建已强制保留default导出并禁止再次捆绑平台Vue/客户端；现有线上host桥接与菜单增量仍需完成，不能直接上传未接好桥接的组件。禁止部署包含无关修改的整份平台dist。真实账号信息由安全渠道配置，store/admin-account.md仅记录准备状态。
