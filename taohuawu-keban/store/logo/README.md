# 桃花坞刻版品牌标

- `symbol.svg`：纯品牌 Symbol 矢量源。
- `logo-horizontal.svg`：横版品牌锁定稿。
- `foreground.png` / `background.png`：HarmonyOS 1024 分层资源。
- `preview-1024.png`：AppGallery 单层图标与工程同步母版。
- `agc-216.png`：216 像素检查版本。
- `render_logo.py`：将本项目的原创几何方案栅格化，不使用通用 Logo 生成模板。

AppGallery 首选上传 `preview-1024.png`。DevEco Studio 建议版本不低于 5.0.5.315；正式发布前仍需在真机桌面和启动窗复核分层效果。
