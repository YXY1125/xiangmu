# Logo Concept — 桃花坞刻版

## 七项主题分析

1. App 名称：桃花坞刻版；品牌锚点是首字“桃”。
2. 核心功能：角色图鉴、文化知识和可恢复的素材组合创作。
3. 使用场景：手机桌面识别、启动页、登录页、首页品牌区、关于页和 AppGallery。
4. 内容主题：桃花坞木版年画的套色与刻版语义，以及现代萌系国潮表达。
5. 目标用户：国潮插画爱好者、传统文化兴趣用户和原创内容创作者。
6. UI 风格：萌系国潮、Q 版动漫、现代编辑式插画、轻木刻质感与潮玩式留白。
7. 主色：界面主色桃花粉 `#F2A6B8`；图标使用深朱砂 `#7B2F39` 与奶油白 `#FFF8F0` 形成高对比。

## 品牌关键词

Peach · Carving · Auspicious · Playful · Craft

## 主题绑定

- brandAnchor：`桃`
- glyphStrategy：`semantic-fusion`
- 核心元素：五瓣桃花 + 中央木版刻刀负形，仅两个视觉语义。
- 构图：五瓣花在中心安全区形成圆润轮廓；中央负形像一枚向下的刻刀刃，也像套色印刷的定位刻痕。
- 风格：扁平、无渐变、无阴影、无发光、无圆角遮罩；缩小到 24px 仍可识别花形与中央刻痕。
- 对比策略：不透明深朱砂背景 `#7B2F39`，前景奶油白 `#FFF8F0`；灰度下仍保持清晰轮廓。

## 与 avoidSlugs 的差异

- 与 `lqzks.tdx.huawei`：不用扇面、竹叶或留青刻纹，主体是五瓣桃花和刻刀负形。
- 与 `txmop.zy.huawei`：不用提线、关节或戏台轮廓，构图为稳定的中心花形。
- 与 `qiaosi-sheji`：不用抽象设计工具或古今拼接符号，品牌锚点直接来自“桃”。
- 与 `ptxj.wb.huawei`：不用照片边框、拼贴块或胶带语义，保持单一花形品牌标。

## 禁止项自检

- [x] 非机器人、灯泡、火箭、六边形、地球、齿轮、盾牌或通用 AI 图标
- [x] 两种实色，无渐变球、3D、投影、玻璃或发光
- [x] 四周安全区不少于图标宽度的 25%
- [x] 方角不透明背景，不在图内预裁桌面圆角
- [x] 独立手写 SVG，不从其他 App 复制路径或位图
