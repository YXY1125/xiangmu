# 咖啡研习间项目概览

咖啡研习间（COFFEE LAB）以“学习—计算—制作—测评—复盘”为核心闭环，包含咖啡知识、制作实验、配方、风味测评、器具百科和个人成长六大体系。五个一级导航为首页、研习、实验室、配方、我的。

权威产品契约为根目录 `AppSpec.json`；Bundle Name 为 `kafyj.zy.huawei`，开发主体为黑龙江省众富信息科技有限公司，华为开发者账号名称及协议运营者为黑龙江省云富信息科技有限公司。两类主体分开记录。默认不启用生成式 AI，不提供商品交易，不虚构品牌价格或用户数据。

公开内容允许游客浏览；收藏、制作记录、私有配方、测评、学习和成长数据必须登录。服务端从签名会话解析租户与用户，不信任客户端 userId。
