# 应用市场审核演示脚本

1. 首次启动，查看隐私提示；注册页协议复选框默认未选中。
2. 使用通过正式流程创建的审核账号登录。
3. 从研习页进入知识详情，完成学习并收藏。
4. 从实验室进入冲煮计算器，输入 15g 与 1:15，核对总水量 225ml。
5. 保存制作记录，并在制作历史中核对当前账号记录。
6. 进入配方详情，复制并编辑个人配方；原版本仍可追溯。
7. 完成七维风味测评，查看雷达图和报告。
8. 在“我的”查看由真实学习、制作、测评行为计算的成长数据。
9. 查看空数据、网络错误、登录失效提示，以及协议、隐私政策和设置入口。

> 上架前由审核人员使用已部署环境逐项复核并记录证据。
