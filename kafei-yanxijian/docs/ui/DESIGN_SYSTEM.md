# COFFEE LAB 设计系统

视觉方向为精品咖啡杂志与现代实验室的结合。主色深咖啡棕 `#241B17`，奶油米白 `#F3EBDD`，焦糖金 `#B47A43`，植物绿 `#687C68`，浅咖啡 `#D8C7B2`，正文深棕 `#3B2A20`。

页面以大标题、不同层级卡片、紧凑数据摘要与清晰动作构成。圆角层级建议 14/18/24/28vp；主按钮高度 44–48vp。加载、空数据、网络错误、只读和提交中状态必须可见。核心统计来自 API，不在无数据时生成虚假值。

当前已实现浅色主主题并通过编译；深色模式、真机对比度和无障碍字号仍需设备验收，因此 UI Quality Gate 未通过。
