# 功能清单

- 五个一级导航：首页、研习、实验室、配方、我的。
- 咖啡知识：分类/关键词筛选、统一搜索、详情、学习完成、收藏、学习历史。
- 制作实验：六类教程入口、粉水实时计算、分段水量、水温、完整制作参数、制作图片、保存与历史筛选。
- 配方：官方配方、复制并调整、自定义配方、配方封面、版本化编辑、个人配方列表、收藏与制作入口。
- 风味测评：七维评分、多选风味标签、保存、统计均值、标签分布与历史。
- 器具百科：分类列表、详情、对比、收藏。
- 个人档案：资料编辑、统一收藏、每日打卡、实时成长统计、近 7 日活动趋势、冲煮方式分布、等级与成就。
- 账号与合规：注册、登录、会话持久化、401 失效、退出、协议主动勾选、账号注销匿名化。
- 数据一致性：写后刷新、旧响应隔离、userId/tenantId 隔离、幂等行为、业务记录不物理删除。
- 默认无 AI 功能。
