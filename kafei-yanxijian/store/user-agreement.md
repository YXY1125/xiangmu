# 咖啡研习间用户协议

运营者：黑龙江省云富信息科技有限公司  
开发主体：黑龙江省众富信息科技有限公司  
更新日期：2026-11-12

咖啡研习间提供咖啡知识浏览、冲煮计算、配方、制作记录、风味测评、器具资料和个人成长档案。公开内容仅作一般学习参考，不构成医疗、营养或商业承诺。冲煮建议应结合咖啡豆、设备、水质和个人偏好调整。

用户可游客浏览公开内容；保存收藏、制作、配方、测评和成长记录需注册登录。注册时必须主动同意本协议和隐私政策，不得冒用他人身份、上传违法或侵犯权利的内容，也不得尝试访问其他用户数据。

用户对主动创建的内容负责。系统对配方和业务记录采用版本化与归档管理，不提供物理删除业务记录的功能。账号注销会停止账号使用、匿名化身份并按规则归档相关记录。

公共内容会持续校正；如资料来源或表述尚待核实，将以待完善状态发布或不公开。应用不虚构咖啡品牌参数、商品价格或用户评价，默认不提供生成式人工智能功能。

运营者可为安全、合规和服务维护更新协议，并以合理方式提示。协议以应用内展示并由用户主动同意的当前版本为准。
