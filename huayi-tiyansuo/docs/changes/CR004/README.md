# CR004 — 法律运营者实名同步

原因：用户提供并核验华为开发者账号实名运营者名称为“黑龙江省众富信息科技有限公司”。该名称与既有开发主体相同，但两项身份仍分别记录。

变更：在 AppSpec `store.legalOperator` 写入已核验名称，同步客户端隐私政策/用户协议、商店隐私政策、用户协议、个人信息收集清单、第三方共享清单及交付检查记录。Bundle Name、业务范围、权限、数据实体、API 契约和 `aiEnabled=false` 均不变。

验证：重新计算 AppSpec SHA-256 并执行 Gate A；检查所有正式法律文本不再含运营者实名占位语。联系方式仍作为发布前独立资料项管理，不以未提供内容冒充完成。
