# CR002 — 全量工坊透明花材精灵图

- 基线：AppSpec 1.2，校验和 `4a63720cb20b1fd813afd0a7d72bea48831cbad75243eeef63b9a752e2534caf`。
- 原因：首期 60 种图鉴花材都需要从详情页进入二维创作画布；新增六张 5×2 RGBA 精灵图，保证每个 `materialId` 对应独立视觉单元；同时补充花篮容器与包装纸、丝带、珍珠、卡片四种装饰。
- 影响：仅增加本 App 视觉资产登记和客户端素材映射；身份、行业包、API、权限、AI 状态不变。

- 质量记录：六张正式文件均为 1983×793 RGBA；配花图四角存在 2–4/255 近透明抗锯齿，其余正式图四角 Alpha 为 0。
- 回退：恢复 AppSpec 1.2，移除六项 `atlas_*_cutout` 登记，并让工坊映射回摄影图集；不影响公共 Schema 和其他租户。
