花艺体验所隐私政策

生效及更新日期：2026年11月13日
应用名称：花艺体验所
运营主体及个人信息处理者：黑龙江省众富信息科技有限公司

一、适用范围

本政策适用于花艺体验所 HarmonyOS 应用。应用提供花材图鉴、花艺课程、二维花艺创作、作品展示与互动、节日活动和成长成就。游客可以浏览公共内容；注册、登录、保存草稿、发布作品、互动、同步学习进度和参加活动时，将按本政策处理必要信息。

二、我们处理的信息

  1. 账号与认证信息：注册账号、密码、姓名、手机号码和选填邀请码，用于创建、验证和管理 saas26 账号。密码由统一认证服务安全处理，客户端不保存输入的明文密码。
  2. 身份与会话信息：用户 ID、租户 ID、登录令牌和协议主动同意状态，用于接口授权、会话恢复及租户与用户数据隔离。
  3. 个人资料：昵称、应用内头像和用户主动填写的资料，用于个人花房和公开作品署名。
  4. 创作与作品：作品名称、背景、容器、花材与装饰、对象坐标、缩放、旋转、图层、主题、挑战、封面、草稿/发布状态及时间，用于保存、恢复、继续编辑、预览和展示。草稿仅本人可访问，只有主动发布后才进入公开花园。
  5. 学习、活动与成长：课程收藏、步骤进度、完成状态、活动参加与作品提交、挑战结果、成就进度及解锁时间。
  6. 收藏与互动：花材、课程和作品收藏，以及作品点赞和取消记录。
  7. 设备与活跃：设备型号、设备类型、应用打开时间，以及系统明确授权 APP_TRACKING_CONSENT 后取得的 AAID。拒绝授权不影响核心功能，AAID 在未授权时为空。

本应用不申请定位、通讯录、麦克风、摄像头或相册全量读取权限，不接入广告、支付或生成式人工智能 SDK，也不会把作品内容发送给大模型。

三、处理方式与保存期限

账号认证和需要同步的业务信息通过 HTTPS 传输至花艺体验所 saas26 认证与业务服务；客户端只调用 API，不直接连接数据库。账号与业务记录原则上保存至用户主动注销并完成服务端清理。法律义务、争议处理或备份轮换导致暂时无法立即删除时，仅继续必要的存储和安全保护，并在相应期限届满或轮换完成后删除或匿名化。

四、公开展示和内容管理

公开作品会展示作品内容、作者昵称、所用花材、主题、发布时间和互动数据。私有草稿、未发布作品、账号资料、学习及活动记录不向其他普通用户开放。平台可对违法、侵权或违反规则的公开内容限制展示或归档，但不会擅自改写用户私有画布正文。

五、共享、服务端和第三方 SDK

当前版本不集成第三方广告、支付、地图、统计或生成式人工智能 SDK。saas26 认证与花艺业务 API 是本应用运营所使用的服务端能力，处理范围限于账号认证、用户隔离、作品、互动、学习、活动和成就记录。未来发生变化时，我们会更新代码、权限、商店隐私标签和本政策，并依法另行告知或征得同意。

六、您的权利

用户可查看和更新本人作品、收藏、学习及活动记录，取消点赞和收藏，编辑草稿并调整发布状态。可在“我的—设置中心—注销账号”经二次确认申请注销，服务端清理成功后客户端才会退出并清除本机会话。用户还可以通过下述渠道提出查阅、更正、复制、删除、限制处理、撤回同意或说明处理规则的请求。

七、未成年人保护

本应用不专门面向不满十四周岁儿童，也未设置监护人同意验证流程。不满十四周岁的用户请勿自行注册、发布或提交活动；确需使用时，应由监护人先联系运营者并完成必要的监护人同意。未成年人不应在公开作品中披露真实姓名、学校、住址、电话等信息。

八、安全与政策更新

我们采取 HTTPS、身份鉴权、租户与用户 ID 双重隔离、私有草稿访问控制、幂等互动和必要的日志审计措施。处理规则发生实质变化时，我们会更新本政策，并在依法需要时重新取得同意。

九、联系我们

如需行使个人信息权利或提出隐私问题，请通过华为应用市场“花艺体验所”详情页展示的黑龙江省众富信息科技有限公司开发者联系渠道与我们联系。本政策不另列未经运营者提供和核验的电话、邮箱或地址。
