## 图集裁切约定

六张花材图集各含 5 列×2 行、共十个互不重复的独立花材单元。业务数据保存 `atlasKey + column + row`；客户端以裁切容器展示对应单元，不把一张整图复制多份冒充不同花材。六张图集共覆盖首期 60 种花材。

工坊另使用六张同布局 RGBA 精灵图叠加创作画布；原始 imagegen 输出保存在 `assets/downloads/source/`。主花、球根花、线条花、叶材、特殊花材四角透明度检查为 0；配花图因细碎花序抗锯齿在四角存在 2–4/255 的近透明像素，已如实记录，不宣称其角点完全透明。

花篮文件四角 Alpha 为 0；装饰精灵图四角为 0–2/255 的近透明抗锯齿。两者均已接入真实画布对象或容器切换，不只登记在文档中。
