# 功能范围

- 首页：品牌主视觉、每日花语、灵感、快捷入口、课程/活动/作品/花材/季节专题。
- 工坊：四类入口、二维画布、背景/容器/素材、独立变换、图层、撤销重做、草稿、预览和保存。
- 图鉴：至少 60 种花材、六类分类、搜索筛选、详情、收藏、随机认识和工坊联动。
- 课堂：至少 20 套课程、图文步骤、学习进度、收藏、记录和工坊联动。
- 花园：推荐/最新/热门/分类、详情、作者主页、本人作品、发布、点赞和收藏。
- 活动：至少六项配置化节日活动、实时状态、参加、创作、提交和历史记录。
- 我的：资料、作品、草稿、收藏、课程、活动、成就和设置。
- 账号：复用 saas26 登录注册、会话持久化、失效处理、退出和注销；注册协议默认不勾选。
- 明确排除：支付、鲜花交易、广告、生成式 AI、假登录、静态假业务记录。
