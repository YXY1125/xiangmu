# 视觉方向

- stylePack：`soft-editorial`
- 主色：植物绿 `#496B55`，深色 `#2E4938`
- 基底：奶油白 `#FFF8EE`，情绪强调为低饱和浅粉
- 首页：自然治愈的花艺杂志构图，摄影先行，区块不做同构白卡堆叠
- 工坊：现代艺术工具界面，画布聚焦，工具区保持高对比和紧凑层级
- 图鉴：植物百科与编辑杂志融合，图像裁切保持物种辨识
- 课堂：步骤导向，图文层次清晰
- 花园：高级画廊风，作品图优先，互动信息克制
- 活动：在统一品牌色上允许节日专属辅助色
