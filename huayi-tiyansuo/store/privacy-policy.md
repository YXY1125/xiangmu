# 花艺体验所隐私政策

生效及更新日期：2026年11月13日  
应用名称：花艺体验所  
运营主体及个人信息处理者：黑龙江省众富信息科技有限公司  
公开地址：https://saas26.qianqi.online/privacy/hytys.xcl.huawei/privacy-policy.html

## 一、适用范围

本政策适用于花艺体验所 HarmonyOS 应用。应用提供花材图鉴、花艺课程、二维花艺创作、作品展示与互动、节日活动和成长成就。游客可以浏览公共内容；注册、登录、保存草稿、发布作品、互动、同步学习进度和参加活动时，将按本政策处理必要信息。

## 二、我们处理的信息

1. **账号与认证信息**：注册账号、密码、姓名、手机号码和选填邀请码，用于创建、验证和管理 saas26 账号。密码由统一认证服务进行安全处理，客户端不保存输入的明文密码。
2. **身份与会话信息**：用户 ID、租户 ID、登录令牌、协议主动同意状态，用于接口授权、会话恢复及确保不同租户、不同用户的数据隔离。退出登录会清除本机当前会话，不会删除云端作品与进度。
3. **个人资料**：昵称、应用内头像和用户主动填写的资料，用于个人花房和公开作品署名。
4. **花艺创作与作品信息**：作品名称、画布背景、容器、花材与装饰素材、对象坐标、缩放、旋转、图层、主题、挑战、草稿/发布状态、封面及创建更新时间，用于保存、恢复、继续编辑、预览和展示作品。草稿仅本人可访问；作品只有在用户主动发布后才进入公开花园。
5. **学习、活动与成长信息**：课程收藏、步骤进度、完成状态、学习记录、活动参加与作品提交、挑战完成情况、成就进度及解锁时间，用于继续学习、校验活动条件和计算真实成就。
6. **收藏与互动信息**：花材、课程和作品收藏，作品点赞及取消记录，用于展示个人收藏、作品互动状态并防止重复记录。
7. **设备与活跃信息**：设备型号、设备类型、应用打开时间，以及在系统明确授权 APP_TRACKING_CONSENT 后取得的 AAID，用于基础兼容分析与真实应用活跃记录。拒绝系统授权不会影响花材浏览、课程、创作等核心功能，AAID 在未授权时为空。

本应用不申请定位、通讯录、麦克风、摄像头或相册全量读取权限，不接入广告、支付或生成式人工智能 SDK，也不会把作品内容发送给大模型。

## 三、处理目的、方式与保存期限

我们通过 HTTPS 将账号认证和需要同步的业务信息传输至花艺体验所 saas26 认证与业务服务；客户端只调用 API，不直接连接数据库。账号与业务记录原则上保存至用户主动注销账号并完成服务端清理；取消点赞、取消收藏或归档作品后，相应状态按业务结果更新。为满足法律义务、争议处理或备份轮换而暂时无法立即删除的信息，将停止除存储和安全保护以外的处理，并在相应期限届满或备份轮换完成后删除或匿名化。我们仅在实现本政策所述目的所需的最短期限内处理个人信息。

## 四、公开展示与内容管理

公开作品会展示作品内容、作者昵称、所用花材、主题、发布时间和互动数据。私有草稿、未发布作品、账号资料、学习记录、活动记录及成就明细不会向其他普通用户开放。用户应避免在作品标题或内容中填写手机号码、住址等不必要信息。平台可对违法、侵权或违反规则的公开内容限制展示或归档，但不会擅自改写用户私有画布正文。

## 五、共享、委托处理和第三方 SDK

当前版本不集成第三方广告、支付、地图、统计或生成式人工智能 SDK。saas26 认证与花艺业务 API 是本应用运营所使用的服务端能力，处理范围仅限账号认证、用户隔离、作品、互动、学习、活动和成就记录。具体清单见《第三方共享与服务清单》。如接收方、处理目的或 SDK 发生变化，我们会在新版本发布前更新代码、权限、商店隐私标签和本政策，并依法另行告知或征得同意。

## 六、您的权利

用户可在应用内查看和更新本人作品、收藏、学习及活动记录；可取消点赞、取消收藏、编辑草稿、调整作品发布状态。可在“我的—设置中心—注销账号”经二次确认申请注销，服务端清理成功后客户端才会退出并清除本机会话。用户还可以通过下述联系渠道提出查阅、更正、复制、删除、限制处理、撤回同意或说明处理规则的请求。撤回同意不影响撤回前基于同意已进行的处理；处理核心功能必需信息的同意被撤回后，相应登录与同步功能可能无法继续提供。

## 七、未成年人保护

本应用不专门面向不满十四周岁儿童，也未设置监护人同意验证流程。不满十四周岁的用户请勿自行注册账号、发布作品或提交活动；确需使用时，应由监护人先通过本政策所列渠道与运营者联系并完成必要的监护人同意。未成年人应在监护人指导下合理使用创作与公开展示功能，不应在公开作品中披露真实姓名、学校、住址、电话等信息。详见《未成年人使用与个人信息保护说明》。

## 八、安全与政策更新

我们采取 HTTPS、身份鉴权、租户与用户 ID 双重隔离、私有草稿访问控制、幂等互动和必要的日志审计措施保护数据。若处理目的、方式、信息种类或保存规则发生实质变化，我们会更新本政策，并在依法需要时重新取得同意。

## 九、联系我们

如需行使个人信息权利、反馈内容或提出隐私问题，请通过华为应用市场“花艺体验所”详情页展示的黑龙江省众富信息科技有限公司开发者联系渠道与我们联系。本政策不另列未经运营者提供和核验的电话、邮箱或地址。
