# 1.0.0 发布说明

- 首发二维花艺创作工坊，支持独立对象拖拽、缩放、旋转、图层、撤销重做及草稿恢复。
- 提供 60 种花材图鉴、20 套课程、8 个创作主题、5 类挑战和 6 项节日活动。
- 上线作品花园、幂等点赞收藏、学习活动记录及 15 项真实成就。
- 支持游客浏览、saas26 账号认证、用户数据隔离和账号注销。

三份公开法律页和 API 24 模拟器核心闭环已完成；画布操作和个人统计同步专项修复也已通过模拟器回归。该修复发生在最近一次正式签名之后，仍需重新签名，并补齐物理真机专项、商店截图和审核账号后随候选包提交。运营者名称及 AppGallery 开发者联系渠道已按同主体既有 App 口径核验。
