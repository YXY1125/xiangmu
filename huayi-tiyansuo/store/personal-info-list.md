# 花艺体验所个人信息收集清单

运营主体及个人信息处理者：黑龙江省众富信息科技有限公司。

| 信息 | 使用场景 | 处理目的 | 必需性与保存 |
|---|---|---|---|
| 注册账号、密码、姓名、手机号码、选填邀请码 | 注册 | 创建和验证 saas26 账号 | 注册时必需，邀请码选填；密码不在客户端明文保存 |
| 用户 ID、租户 ID、登录令牌、协议主动同意状态 | 登录及所有私有接口 | 身份鉴权、会话恢复、租户和用户数据隔离 | 登录与同步必需；退出时清除本机会话 |
| 昵称、应用内头像 | 个人花房、公开作品 | 个人资料展示和公开署名 | 用户主动使用相应功能时处理 |
| 作品名称、画布背景、容器、花材/装饰 ID、坐标、缩放、旋转、图层、主题、挑战、封面、草稿/发布状态 | 花艺工坊与作品花园 | 保存、恢复、继续编辑、预览和展示作品 | 保存作品时必需；草稿仅本人可见 |
| 花材、课程和作品收藏，作品点赞/取消记录 | 收藏与互动 | 展示个人收藏、互动状态、防止重复记录 | 使用相应功能时处理 |
| 课程步骤、学习进度、完成状态和学习时间 | 花艺课堂 | 继续学习、完成校验和成就计算 | 保存进度时处理 |
| 活动参加、任务进度、作品提交记录 | 节日花事 | 活动条件校验、进度和参与记录 | 参加活动时处理 |
| 成就进度、解锁状态和解锁时间 | 成就中心 | 根据真实业务记录展示成长 | 使用登录功能时处理 |
| 设备型号、设备类型、打开时间 | 登录与应用活跃 | 基础兼容分析和真实活跃记录 | 设备型号随认证/活跃请求处理 |
| AAID | 登录后的系统授权场景 | 基础应用活跃统计 | 可选；仅在 APP_TRACKING_CONSENT 授权后取得，拒绝不影响核心功能 |

账号与业务记录原则上保存至用户主动注销并完成服务端清理。法律另有规定或备份轮换暂时无法立即删除时，仅继续进行必要的存储和安全保护，并在相应期限届满后删除或匿名化。

本应用不收集精确位置、通讯录、录音、摄像头内容或相册全量内容，不接入广告、支付或生成式人工智能 SDK。权利请求和隐私问题请通过华为应用市场本应用详情页展示的运营者开发者联系渠道提出。
