# 页面架构

## 一级导航

1. **首页 / 年画新世界**：原创角色主视觉、搜索、每日文化、创作入口、互动入口、专题、热门文章和节日活动。
2. **年画馆**：文化文章、角色系列、六个专题及详情浏览进度。
3. **创作**：20 套模板、自由创作、背景/角色/纹样/贴纸/文字/图层工具、保存、预览与导出。
4. **乐园**：拼图、火眼金睛、福气配对、知识问答、纹样寻宝。
5. **我的**：用户资料、收藏、图鉴、作品/草稿、游戏与学习记录、成就、设置和协议。

详情采用一级页面内覆盖层或独立路由，关闭后回到原列表状态；登录页不作为启动隐私弹窗，协议默认不勾选。

## 代码职责

- `pages/`：主页面、登录与容器导航。
- `components/`：首页、文化馆、编辑器、游戏、个人中心及详情组件。
- `models/`：文化内容、作品图层、记录等强类型模型。
- `data/`：可审计的应用内文化内容与原创角色目录。
- `services/`：本地持久化、平台内容、云同步和作品导出。
- `utils/`：媒体资源解析和通用转换。
