# 功能与页面架构

## 五个主导航

1. 首页「年画新世界」：品牌主视觉、角色、每日文化、工坊、乐园、专题、热门内容、节日活动。
2. 年画馆：文化文章、四系列角色图鉴、六个数字专题及详情。
3. 创作：20 套模板、自由画布、背景/角色/纹样/贴纸/文字、图层编辑、撤销恢复、保存、再次编辑、PNG 导出系统相册。
4. 乐园：年画拼图、火眼金睛、福气配对、知识问答、纹样寻宝。
5. 我的：用户资料、收藏、图鉴、创作、草稿、游戏、学习、成就、设置、协议、关于。

## 数据闭环

收藏、作品完整图层配置、游戏成绩、学习记录和专题进度使用 Preferences 持久化；键名按游客或当前登录用户名隔离。图片文件保存在应用缓存/系统相册，不写入键值存储。
