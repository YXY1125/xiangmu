# 朱仙镇年画差异化说明

对照对象：`ylqnhp.tdx.huawei`（同传统年画行业包）、`txmop.zy.huawei`（非遗角色创作）、`dgllz.tdx.huawei`（传统工艺参数化创作）。本项目不复制其业务实体、Tab、种子、图片或首页实现。

1. **唯一文化锚点不同**：本应用聚焦朱仙镇木版年画，公共内容围绕门神文化、套色印刷、吉祥图案、瑞兽与新春民俗；不复用杨柳青年画题材、木偶戏剧目或琉璃珠工艺内容。
2. **主闭环不同**：本应用是“可信文化发现 → 原创角色理解 → 多图层创作 → 游戏/学习复盘”，不是“图鉴 → 图库下载”、木偶操演或珠体参数设计。
3. **五导航不同**：固定为“首页 / 年画馆 / 创作 / 乐园 / 我的”。第四入口是五种真实可玩的文化游戏，不是图库、技艺课堂或泛探索。
4. **核心实体不同**：使用 `NewYearPicture`、`Character`、`CharacterAsset`、`Exhibition`、`CreativeTemplate`、`UserArtwork`、`ArtworkLayer`、`GameConfig`、`GameRecord` 等；角色统一性和游戏状态是一级数据模型。
5. **工作台不同**：`workbenchId=zhuxianzhen-print-playground`，首页首屏用原创角色主视觉与“继续创作”单一动作，下面是杂志式错落策展；不采用 `nianhua-layer-studio` 的图库下载结构、`puppet-stage-studio` 舞台结构或 `glass-prism-atelier` 参数面板。
6. **布局变体不同**：采用 D 变体的非对称策展与状态摘要，避免 E 变体工具优先、C 变体双栏或 prism-asymmetry；不出现三列等宽 KPI、通用快捷宫格和 AI 横幅。
7. **原创角色资产不同**：首期四系列十二角色，头像、立绘、表情、贴纸通过唯一角色 ID 和资源关系保持一致；历史人物文化原型与现代原创改编在详情中明确区分。
8. **编辑器验收不同**：支持 1:1、3:4、9:16，保存画布、背景、完整图层、文字对象、坐标、尺寸、旋转、层级与透明度；重新打开必须恢复全部状态，不以最终图片代替编辑工程。
9. **玩法系统不同**：拼图、找不同、配对、问答、纹样寻宝分别具有配置、难度、进行中、暂停、退出、结束、结算和记录，不用统一按钮计数器冒充五个游戏。
10. **视觉签名不同**：品牌色使用用户指定朱砂红 `#A52C32`，配合鎏金、宣纸白和青绿；视觉签名为“木版套色边缘 + 年画门楣 + Q版角色贴纸切片”，不复制其他 App 影像或 Logo。
11. **内容真实性不同**：所有传统作品、历史与工艺内容记录来源；现代原创故事和 AI 生成视觉明确标记，禁止作为真实历史作品或馆藏展示。
12. **游客策略不同**：公共文化与本地基础创作可游客使用；收藏、云同步、跨设备恢复和账号成就才触发登录，满足核心功能不强制注册，同时保持账号数据隔离。

## 结构指纹自检

- 首页无通用大标题 + 空待办 + 三 KPI + 同构宫格 + 实色 AI 横幅组合。
- 首页首屏为主题影像与单一创作动作，后续角色、专题、知识、作品和活动采用不同图片比例与节奏。
- 创作页以画布为中心，工具围绕画布分区，不让装饰卡片挤占工作区。
- 乐园入口有封面、玩法、难度和成绩；每种游戏进入独立状态机。
- 年画馆与详情页优先呈现来源、文化语境和工艺信息，不做普通商城或博物馆管理系统。
