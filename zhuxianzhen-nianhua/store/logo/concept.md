# Logo Concept — 朱仙镇年画

## 主题绑定

- App：朱仙镇年画
- 开发主体：黑龙江省众富信息科技有限公司
- 行业：朱仙镇木版年画文化鉴赏、原创角色与分层数字创作
- 气质：`guochao-chibi-woodblock-v1`，现代、亲和、克制，保留木版套色的硬朗边缘
- brandAnchor：`朱`
- 品牌关键词：Woodblock / Guardian / Auspicious / Playful / Craft
- 核心元素：门楣轮廓 + “朱”字几何负形，共两项

## 构图

图形以对称门楣建立“守门”和年画入口语义，中部使用六段粗线重构“朱”字。字形不依赖系统字体，缩小到 24px 仍能由横、竖、撇、捺的主骨架辨认。门楣与字形共享中轴，避免复杂插画和装饰堆叠。

## 色板与对比

- 图标背景：深朱砂 `#6E1E24`
- 图标前景：宣纸白 `#F7EEDB`
- 仅使用两种实色；无渐变、阴影、发光、玻璃或透明圆角
- 深底与浅标具有明显明度差；前景主体限制在画布中部约 64%，四周保留充足安全区

## 与 avoidSlugs 差异

- 与 `ylqnhp.tdx.huawei`：本稿以“朱”字与门楣融合，不采用杨柳青年画铺的铺面、画卷或通用年画框图形。
- 与 `txmop.zy.huawei`：本稿没有提线、舞台、木偶关节或戏台轮廓，视觉重心是门神文化入口。
- 与 `dgllz.tdx.huawei`：本稿不使用珠体、火焰、棱镜或蓝色玻璃质感，采用朱砂与宣纸的平面木版语言。

## 禁止项自检

- 无 AI 大脑、机器人、灯泡、火箭、盾牌、齿轮、地球、无限符或六边形科技模板
- 无渐变球、3D、投影、发光、毛玻璃、液态或复杂纹理
- SVG 不嵌入位图、base64、filter、mask 或 clipPath
- 图形为本 App 新写，不复制其他项目 Logo
